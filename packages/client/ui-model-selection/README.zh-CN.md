# @workbench/ui-model-selection

Owns model selection state, view, reasoning labels, store, and extension registration. Labels are provided by the local bilingual bundle; consumers use the public `./models`, `./reasoning`, and `./selector` entries.

负责模型选择状态、视图、推理标签、store 和扩展注册。文案由本包双语词典提供；消费者使用公开的 `./models`、`./reasoning` 和 `./selector` 入口。
