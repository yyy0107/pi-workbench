## 旧包收口

- ui-agent-controls 在模型与 token 两个 owner 完成后删除；不留空壳或生产转发。
- ui-settings 保留 Settings registry/main view/request/sidebar/command 容器；general 不接走容器。保留的设置搜索/分组算法提到真实 lib，避免 lib 被拆空。
- pi-ui-settings 保留 agent prompt/configuration、cache notice 和 prompt-placeholder helper；models 独立。
- composer 保留 Lexical 编辑器、document/history/submit 和输入区装配；attachments 和 trigger 改公开依赖。
- conversation 保留会话列表、消息/回合装配、viewport/scroll、file/image/text/source renderers；不再承载上述各项产品扩展。
- side-chat 依赖剩余 conversation 的公共视图是允许的；删除 conversation/side-chat 转导出后依赖不会闭环。

## 附加候选的处理

- 目录选择：本期保留 workspace-directory-picker。remote/native 共用 admission/取消/回退生命周期，native 尚无独立真实 helper；不将现有分支强拆成两个互相引用的包。其 ui-selectors 基础已独立。
- 工具箱：pi-ui-toolbox 的 skill/prompt/package inventory 确有混合职责，但本期不移动；下一轮需先拆 catalog/scope/file opener 共享契约。不能只按 skill 等关键词搬 use-pi-skill-details。
- 本期新增15个目标owner，移除旧 ui-agent-controls，预计净增14包；该数字是计划核对值，不是验收通过或包数目标。
